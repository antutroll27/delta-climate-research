How comparison works ↓
Comparison integrity

Production comparison will use equal 1.4 km study windows, one frozen regional forcing, one model version, north-up 2D maps and a fixed 26–48°C scale.

Production outputs will compare model response—not vulnerability, equity, feasibility or investment priority.

Production share links will pin forcing, model, grid/data and backend release identifiers so a saved comparison remains reproducible.

Capital works use regional benchmark ranges and exclude operations, maintenance, land, design, utilities, irrigation and site constraints. Park cost follows planted area; site equivalents use the 0.785 ha standard.
