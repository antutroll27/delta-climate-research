# Inspiration

Drop reference images here (PNG / JPG screenshots from Pinterest, Awwwards, Dribbble, real sites, etc.).

## Tips for best results
- **Screenshots > links** — I can open local image files directly; Pinterest/Dribbble often block automated fetching.
- **Annotate if you can** — rename the file or add a note describing *what* you like about each one, e.g.:
  - `feed-spacing-darkmatterlabs.png` — "love the dense row spacing"
  - `cyan-glow-hero.png` — "this exact accent glow"
  - `map-dashboard-vibe.png` — "this is the Medni map feel"
- Group loosely if you want: `nav/`, `feed/`, `map/`, `type/`, `color/` subfolders are welcome but not required.

When you're done, just say **"look at the inspiration folder"** and I'll go through everything and fold the relevant cues into the design before we lock the spec.
