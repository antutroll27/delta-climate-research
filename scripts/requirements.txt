# Runtime dependencies of the scripts/ data pipeline.

# WHY THIS FILE EXISTS (added 2026-08-10). It did not, and its absence was
# invisible until mypy was wired into CI: the type checker has to IMPORT these to
# read their inline hints, so `pip install -r requirements-dev.txt` alone leaves
# every `import numpy` unresolved and the gate passes vacuously.
#
# Versions are pinned to exactly what the tree was type-checked against on
# 2026-08-10 — a floating pin would let CI and a developer's machine disagree
# about the same source, which is the same failure mode requirements-dev.txt
# already argues about for stubs.
#
# NOT a distribution manifest. This is a pipeline, and these are the versions
# whose type information the `python3 -m mypy` gate was verified green against.

# (2026-08-02) before scipy was pinned here, and 2.5.x cannot coexist with this

# string differs — so this is not a reproducibility problem, and bumping numpy
